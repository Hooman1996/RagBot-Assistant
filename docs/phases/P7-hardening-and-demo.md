# P7: Demo Hardening and Review

**Goal:** a repeatable, honest presentation for the app team and management.
**Gate (plan §17):** a repeatable acceptance report and presentation, private evidence links,
failures and unknowns honestly scoped, and an independent manager review.

| Task | What it will do |
|---|---|
| P7-01 | Fault scenarios: service failures, malformed output, lost responses, uncertain submission |
| P7-02 | Restart and resume: backend restart, app background and reconnect from the journal plus a fresh observation |
| P7-03 | Bounded load and latency baseline (p50/p95) on the demo hardware, then freeze the budget |
| P7-04 | Clean install, reset and runbook. Three clean demo runs on the pinned emulator. |
| P7-05 | Acceptance report: commits, APK hash, profile and model versions, run counts, failures |
| P7-06 | Presentation: demo script (plan §19), sanitized evidence and fidelity report, and the private findings report for the owner |
